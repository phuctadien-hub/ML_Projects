# ML Projects

This repository contains a small NumPy-based machine learning example that illustrates linear regression and the concept of overfitting.

## Project purpose

The script in [overfitting.py](overfitting.py) demonstrates:

- fitting a model using a polynomial-like feature set,
- comparing it with a simpler model,
- calculating prediction error,
- visually reasoning about how a more complex model can overfit the training data.

## Requirements

- Python 3.10+
- NumPy

Install dependencies:

```bash
pip install numpy
```

## Run the example

```bash
python overfitting.py
```

## Files

- [overfitting.py](overfitting.py) — training and prediction experiments with NumPy
- [gitignore.txt](gitignore.txt) — legacy ignore file from earlier setup

## Notes

This is a beginner-friendly example for learning how model complexity affects fit quality and generalization.
